# alchemy-forge

(Repository preserved in its original static HTML/CSS/JS form.)

This project is a static site built with plain HTML, CSS, and JavaScript. I made only conservative, low-risk improvements on the upgrade branch so the repository remains static and unchanged in behavior.

Local preview

- This is a static site. To preview locally, open index.html in a browser (no build required). For a quick local server (optional), you can run:

  npx http-server -c-1 .

(That command requires Node.js; it is optional and only for convenience.)
